## Hi there 👋
# NTI Program Projects

A collection of full-stack projects built during the NTI (National Telecommunication Institute) program. Each project follows a three-part architecture: a public-facing **frontend**, a **dashboard** for admin/user management, and a **backend API** to power them both.

## 🏗️ Project Structure

Every project in this organization is split into three repositories:

| Role | Purpose | Access |
|------|---------|--------|
| **Frontend** | The public-facing app everyone sees | Public |
| **Dashboard** | Admin/user control panel | Restricted |
| **API** | Backend that powers both | Public |

## 📦 Projects

### 🎨 Portfolio
A personal portfolio website with a management dashboard and supporting API.

- [portfolio](https://github.com/NTI-Program-Projects/portfolio) — Public site (HTML)
- [portfolioDashboard](https://github.com/NTI-Program-Projects/portfolioDashboard) — Admin dashboard (TypeScript)
- [Portfolio-API](https://github.com/NTI-Program-Projects/Portfolio-API) — Backend API (JavaScript)

### 🛒 E-Commerce
A full e-commerce platform with a storefront, seller dashboard, and REST API.

- [ecommerce](https://github.com/NTI-Program-Projects/ecommerce) — Storefront (HTML)
- [ecommerceDashboard](https://github.com/NTI-Program-Projects/ecommerceDashboard) — Seller dashboard (TypeScript)
- [E-Commerce-API](https://github.com/NTI-Program-Projects/E-Commerce-API) — Backend API (JavaScript)

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript, TypeScript
- **Dashboard:** TypeScript
- **Backend:** Node.js, Express, JavaScript
- **Database:** MongoDB
- **Tools:** Git, GitHub, REST APIs

## 🔍 Browsing Tips

Since each project spans three repos, use **topics** to find them together. For example, search `topic:portfolio-project` or `topic:ecommerce-project` to see all related repositories at once.
